
# ExpenseFlow — Personal Expense Tracker
## 🌐 Live Demo

Try ExpenseFlow here: https://expenseflow-c1zu.onrender.com/


ExpenseFlow is a personal expense management web application built using Flask and SQLite.

## Features

- Add, edit, and delete expenses
- Categorize expenses
- View monthly spending summaries
- Set a monthly budget
- Search and filter expenses
- Visualize spending by category using charts

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- Chart.js

## Run Locally

1. Clone or download this repository.
2. Create a virtual environment:

   ```bash
   python -m venv .venv
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   python -m flask --app main run --debug
   ```

5. Open http://127.0.0.1:5000/ in your browser.

## Database

The app uses SQLite. The local database file is excluded from Git to protect personal expense records. A new database is initialized automatically when needed.
